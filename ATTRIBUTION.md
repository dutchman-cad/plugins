- Dutchman core: path dependency from ../dutchman; adapted SolidCraft writer helpers
  are local copies from that checkout,
  Apache-2.0, inspected checkout `90d67b49756c528b5b0b790671358486bd4bec4e`.
  `plugins/importer-common/src/decode.rs` is adapted from that checkout's
  crates/dutchman-core/src/decode.rs: removed filesystem format detection and upstream tests.
  Panic guards and neutral-model validation are preserved; codec selection is
  restricted to the four manifest formats rather than constructing the all-formats
  registry. Geometry depth is requested directly because the output uses only an
  Import feature; omission of editable history is always reported. It remains Apache-2.0.
  plugins/importer-common/src/container.rs is copied from the same checkout's
  dutchman-solidcraft/src/container.rs; document.rs preserves its geometry-import
  document helpers, with a small geometry-only loss-report adapter. Both remain
  Apache-2.0. step.rs is adapted from the same writer: it constructs StepCodec
  directly and inspects helix definitions through typed fields instead of serializing
  the entire model, preserving the guarded restatement and its loss checks.
